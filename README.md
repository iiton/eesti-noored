# Eesti noored: töö, õpe ja muutus ajas

Eesti 15–24- ja 25–34-aastaste tööturu, õppimise ja sissetuleku uurimus. Põhivõrdlus 2005–2025, ajaloolised read alates 1989 ja kvartalid kuni 2026.

- index.html: põhiuurimus, graafikud ja 35 Statistikaameti tabeli andmeuurija.
- cohorts.html: põlvkonna suuruse tingimuslike seoste analüüs ning ligikaudsed põlvkonnateekonnad. Seost ei tõlgendata põhjusliku mõjuna.
- research.html: allikad, ühikud, piirangud ja taastootmine.
- review.html: andmete ja veebivaate ülevaatuse leiud.

Staatiline HTML/CSS/JavaScript. Käitamisel puudub serveripoolne sõltuvus; ECharts on kaasas kohalikult. Avalda GitHub Pagesis haru main juurkaustast.

Andmeseis: 20.11.2026. Allikad: Statistikaamet ja Eurostat, viited lehtedel ja data/sources.json failis. See ei ole Statistikaameti ametlik väljaanne.

Node.js kogumis-, analüüsi-, ehitus- ja kontrollskriptid on failis data/reproduce.ndjson.gz; fikseeritud algandmed failis data/raw-archive.ndjson.gz. Arhiivide vorming on kirjeldatud research.html lehel.
